G0-D3 Sources: existing VERIFIED GROUND segments of the AVE_0 main component, C-state CONDITIONAL_VERIFIED roads (C01, C02, X01, H02 on formal data; chosen by state, never by id), U01 existing. Excluded: NOT_FEASIBLE/UNVERIFIED roads (H01), non-main segments, ELEVATED/RAMP/UNKNOWN, AVE110 extension, selected streets as sources, recursion.
G0-D4 Candidate generation: along each source's filleted centerline, starts every 25 m from the start vertex plus the final endpoint (kept once), local tangent, left/right perpendicular, lengths 30/60/90/120/150 m, straight only. Dedup key (start x,z rounded to 0.01 m, direction rounded to 0.001, length) across sources, first source in sort order wins (source id, distance, side, length). Region filter: start inside the scenario polygon, boundary inclusive; only filtered candidates count toward the budget. Budget per region and scenario: 1,280 (Martin, replaces the draft's 1,024 and the v1.4 256). Budget exhausted -> SEARCH_BUDGET_EXHAUSTED, never a proof.
G0-D5 Street legality. Tier 1 (raster, B masks, 11 m corridor, 1 m cells): blocked / unknown / S1-S4 terrain / outside physical support rejects; axis-aligned corridors by prefix sums, oblique by scanline paint. Tier 2 (exact, only for the best-scoring candidates in order, bounded verify count 24 per round): evaluate_road on a 2-point road_spec (7 m, half 5.5 m, 6 %) must return no BLOCKING and no UNVERIFIED obstacle, grade ok, COR margin ok. Beach: a street with beach_encroachment_m2 > 0 is rejected (BEACH_ENCROACHMENT_NOT_APPROVED); C01/C02 beach stays as reported by T-016C.
G0-D6 Junction and region boundary. Streets are always perpendicular to the source tangent. Overlap with ROAD/SIDEWALK of the source segment (or candidate-road corridor) must be one contiguous run from the start piece; run length <= 30 m (measured 21 m, source half <= 18 m + street half 5.5 m + one 3 m step); overlap with any other ROAD/SIDEWALK, re-entry, or longer run is BLOCKING. Corridor pieces after the run must lie inside the closed scenario polygon; the run pieces may lie outside (external connection, marked external_connection_outside_region true, area not counted). No other outside-region geometry.
G0-D7 Direct preservation. Direct parcels (from G0-D2) are seeds. A source road or street whose corridor overlaps a seed parcel is excluded from that scenario's conditional analysis with reason DIRECT_PARCEL_CONFLICT and the conflicting parcel ids (formal: C01 vs one B1 parcel). No direct parcel is deleted or moved. The exclusion removes dependent chains (a parcel depending on an excluded road is not confirmed).
G0-D8 Greedy street selection: score = number of distinct geom-valid common center cells whose parcel box (any region prototype, both orientations) passes evaluate_access (R7: gap <= 2.0 m, contact >= 8.0 m) against the street corridor and is not overlapping seeds or already selected corridors; ties: shorter length, then candidate order. Up to 3 streets per region and scenario (max 450 m); stop early when no score gain. Selection updates the road mask, the seed set and remaining candidates; no combination search; no claim that other layouts do not exist.
G0-D9 Conditional layout. Seeded place_layout (the approved B edit, section 4) on the common valid masks with an access wrapper over existing + CONDITIONAL_VERIFIED road + selected street corridors. Seeds count in ratios; trimming never removes seeds. C_conditional includes C_direct; C_additional = C_conditional - C_direct. Each parcel status: DIRECT, CANDIDATE_ROAD_REQUIRED, INTERNAL_STREET_REQUIRED (record source_road_id, internal_street_id, external_connection_id, dependency_chain, required_engineering). FOUNDATION_REQUIRED: B masks only admit S0 terrain, so no foundation land is counted; foundation-dependent land stays UNVERIFIED and out of C_conditional. B2 R05 stays PROXY.
G0-D10 Cross preset. Layout verified in PHONE_LOW and DESKTOP_HIGH with _verify_layout (corridor flags: candidate corridors passed with existing:true only inside this verification call, the real flag kept in the record). C_phone_low, C_desktop_high, C_common as in B (R5 adopt rule); never min() of two independent counts.
G0-D11 Land accounting per region and scenario, exclusive cells: A_protected, A_unknown, A_unavailable, A_conditional(foundation S1-S3), A_new_road (cells of conditional roads + selected streets that were otherwise eligible, inside the polygon), A_direct (remaining). Conservation error <= 1 m2. A_eligible = A_direct + A_conditional (B contract, land) and A_eligible_final = A_eligible - A_new_road cells counted once. Beach disclosed separately (beach_encroachment_m2 of used roads), never turned into residential land.
G0-D12 25 ha verdict per scenario: NOT FEASIBLE WITHIN AUDITED BOUNDARIES if A_gross < 250,000 or the proven upper bound (sum of A_possible) < 250,000 (formal INITIAL: 208,676); FEASIBLE if A_direct_final total >= 250,000 and each region has >= 1 DIRECT parcel and no UNVERIFIED input; CONDITIONAL if not FEASIBLE and (A_direct_final + A_conditional_final) total >= 250,000 and each region has a confirmed layout that may depend on conditional roads/streets; else UNVERIFIED.
