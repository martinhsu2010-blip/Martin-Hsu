## 2. Binding conditions (summary; full text in the review)
- **A2-C1** Diagnostic mode sets `renderer.info.autoReset = false` and calls `renderer.info.reset()` before each rendered frame; counts cover all passes (shadow, post-FX). Normal mode never touches `autoReset`. Negative control: default `autoReset` makes G08/G12 red. No "VRAM" naming.
- **A2-C2** `interval_N` = rAF time between consecutive **rendered** frames. Five `performance.now()` points per frame give `pre/physics/update/render/total`. A long interval is attributed to the **previous** frame's CPU; `unattributed = interval - total_prev` is reported separately. No interval for the first frame of a segment.
- **A2-C3** Automatic foreground-time segments: COLD 0-60 s (frozen snapshot), WARM_UP 60-120 s (kept, not a result), MEASURE_1..n each 60 s (max 8 frozen). Long-frame event ring of 32 (COLD has its own): any interval > 100 ms or any program-count increase, with timestamp, interval, previous-frame CPU parts, unattributed, deltas of programs/textures/geometries and new program names. Segment totals (count, >50, >100, max, time of longest) use exact running accumulators; percentiles use the 60 s window.
- **A2-C4/C7** The 0.2 ms overhead target is a SOFT_TARGET: mean per-frame sampling cost measured over >= 10,000 in-page batch calls; the 1 Hz statistics cost is reported separately; timer resolution estimate recorded; diagnostics-caused long frames are never removed.
- **A2-C5** Segment signature = preset, resScale, fpsCap, usePostFX, innerWidth x innerHeight, effective pixel ratio; any change closes the segment (INCOMPLETE if < 60 s) and restarts at WARM_UP. `visibilitychange` and `STATE.pauseRender` are interruptions (first frame afterwards has no interval; interruption count and hidden time recorded). Foreground long frames are always kept; a >= 1 s rAF gap without visibility event gets `foreground_stall`, flagged only.
- **A2-C6** CACHE name from `caches.keys()` matching `^vh-` (exactly one, else UNAVAILABLE with the list); no `sw.js` change or fetch. Refresh-rate estimate from the first 120 raw rAF intervals (ESTIMATE) or UNAVAILABLE.
- **A2-C8** Typed-array ring of 16,384 samples (< 1 MiB), 60 s window, overflow only when an in-window sample is overwritten; nearest-rank percentiles on a preallocated scratch array, at most once per second, no new objects. `contacts` = last internal step's `physicsWorld.contacts.length`, plus `substeps`; `bodies`/`shapes` once per second.
- **A2-C9** Line plan per A2-C9 above (section 1).
- **A2-C10** HUD at most 4 monospace lines (phase/sequence; mean/min 1 s; P50/P95/P99 with >50/>100 counts and longest; CPU P95 x3 + bodies/shapes/contacts + draw/triangles/programs + sample count and segment state). English technical labels, no `tr()` keys. Every B4 field must be readable from the HUD; full data from read-only `__VH.diag.snapshot()`.
- **A2-C11** Node tests use the existing `section()` banner extraction with independently written expected values (nearest-rank on the fixture `[16,20,30,33,33,40,50,51,100,120]`: P50 33, P95 = P99 120, >50 = 3, >100 = 1). G12/G13 compare BASE vs A2 `renderer.info` with an external `autoReset=false` harness (difference 0). The contacts-delta gate applies only if BASE-vs-BASE repetition is identical, else INCONCLUSIVE (bodies, shapes only). Static diff scan: no chunk/registry/LOD controller/`renderer.compile`/new `localStorage` key/`fetch`/CDN. Each negative control has a distinct failure assertion separating assertion failure from environment error; extra controls: default `autoReset`, window-size change without segment split. G16 runs the AGENTS.md required checks and `pwatest.py`; the save-compatibility evidence is listed explicitly in the PR.
- **A2-C12** Core device matrix: S26 Ultra PHONE_LOW and PHONE_MED, Tab S11 TABLET_MED; scenes CBD 12:00, CBD 23:00 and Suburbs (A1 coordinates); about 5 min per scene, 45-60 min total in two sessions, battery/temperature noted.
