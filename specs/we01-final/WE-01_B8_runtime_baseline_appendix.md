- 擁有者：Claude（獨立量測）；日期 2026-11-28；量測對象 main `378ac4b`；對照 BASE `84319439243b51aa8d119e33eb62a0637feea887`（release vh-2026-11-27-02）
- 依據：WE-01 spec v1.2 §13；遊戲原始碼相對 BASE 差異：0 個檔案（`git diff` 對 index.html／sw.js／manifest.json 為空，且 BASE 之後僅有 specs／tools／docs／.github／文件變更）。
- **所有數字皆來自 headless Chrome + SwiftShader 軟體繪圖，只能用來比較『同一方法下的相對變化』，不是 S26 Ultra 或 Tab S11 的 FPS，也不代表新住宅區能達到 30 FPS。本附錄不作任何此類宣稱。**

## 1 量測方法

- 預設組：PHONE_LOW、TABLET_MED、DESKTOP_HIGH（DESKTOP 因 headless 回報 SwiftShader，以偽裝 WEBGL_debug_renderer_info 進入；載入後等待 `__phDone`）。視窗 800×450。
- 六個固定地點，日（12:00）與夜（23:00）各量一次：B1(240,1080)、B2(−700,945)、B3(−490,−710)、Site A(−501,−790)、CBD(−60,0)、Suburbs(−1060,−238)。每處暖機 20 幀後記錄 **120 個完整幀**（`window.__animate` 手動推進，固定 dt=1/60；關閉 dayCycle、fpsCap=0）；報告中位數與範圍。
- 地點未做調整：六處皆 `insideBuilding=false`，玩家落地高度 B1/B2/B3/Site A/CBD 為 0、Suburbs 為 4.35（地形高度），皆為正常地面。
- 渲染 pass：以包裝 `renderer.shadowMap.render` 與 `renderer.render` 取得各 pass 的呼叫數、三角形與 CPU 提交時間。**GPU 時間無法在此環境可靠分離；陰影 pass 的 CPU 提交時間低於計時解析度，顯示為 0，標記為『無法可靠分離』。** 原始碼中不存在水面鏡射 pass，故無此項。
- 物理：5 組配對（BASE 與 main 交替、順序見原始 JSON），每組 900 步暖機＋360 步記錄，使用既有 `physicsWorld.step(1/60,1/60,3)`；原始樣本全數保存在附檔 JSON。
- Baseline control：BASE 與 main 原始碼逐位元相同，故兩者配對比率即為 control；中位數須落在 1/1.10（0.909）至 1.10。

## 5 零變更限制（§13.5）

| 項目 | 結果 |
|---|---|
| 遊戲原始碼檔案 | Δ0（index.html、sw.js、manifest.json 與 BASE 逐位元相同） |
| PWA 資源／存檔結構 | Δ0（無檔案變更） |
| 物理 bodies／shapes、materials | PHONE_LOW、TABLET_MED、DESKTOP_HIGH 皆 Δ0 |
| draw calls／三角形（同狀態：每處、每時段重新載入頁面，比對前 30 幀逐幀） | PHONE_LOW 12/12 相同；TABLET_MED 12/12 相同；DESKTOP_HIGH 9/12 於首次比對相同，其餘 3 項見下 |

**DESKTOP_HIGH 的 3 項差異（B3 日、Site A 日、Site A 夜）已查明為非決定性載入競態，不是遊戲差異：**

- 同一份 BASE 程式碼重複載入 3 次，其中 1 次的場景 meshes 為 1613、`STATE.ferrariLOD` 缺席，其餘 2 次為 1593、`ferrariLOD` 存在（BASE 自己與自己就不同）；main 3 次皆為 1593。DESKTOP 載入含非同步的 PolyHaven 立面模型與 LOD 狀態，量測時點不同即得到不同結構。
- 依 spec 『相同可比較狀態』原則，對這 3 項重新載入，只比較結構簽章（meshes／geometries／geometry buffer）相同的 BASE 與 main：
  - B3/day：簽章 [1593, 814, 293266436]；draw calls 逐幀相同＝True，三角形逐幀相同＝True
  - SiteA/day：簽章 [1593, 814, 293266436]；draw calls 逐幀相同＝True，三角形逐幀相同＝True
  - SiteA/night：簽章 [1593, 814, 293266436]；draw calls 逐幀相同＝True，三角形逐幀相同＝True
- 未修改基準或量測條件來取得通過；差異來源已確認為載入狀態。

## 6 判讀限制

- 所有 ms 為 headless SwiftShader（CPU 軟體繪圖）數值，只在同一方法下比較；不得換算成手機或平板 FPS。
- 連續量測（同一頁面依序換地點）會殘留交通、樹碰撞、LOD 等狀態，BASE 與 main 的連續數值因此可能不同；零變更判定一律採用『每處重新載入頁面』的同狀態比對。
- 本量測描述『現有世界』的基準，沒有新增住宅區；對 WE-02 以後的新建物件，本附錄不構成任何 30 FPS 或預算通過的證明。
- 沒有 CACHE 變更、沒有遊戲程式碼變更。
